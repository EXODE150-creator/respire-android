# Respire, fichier d'installation Android

Respire est une application gratuite pour suivre ton sommeil et avancer face au
tabac, au cannabis ou à l'alcool : journal, SOS envie, repères personnels.

Site : https://exode-respire.netlify.app

Ce dépôt sert seulement à distribuer le fichier d'installation (APK). Le code
source de l'application n'y est pas.

## Télécharger

**[Télécharger Respire (dernière version)](https://github.com/EXODE150-creator/respire-android/releases/latest/download/Respire.apk)**

Toutes les versions et leurs nouveautés : [Releases](https://github.com/EXODE150-creator/respire-android/releases).

## Installer

1. Ouvre le lien ci-dessus sur ton téléphone Android (Android 7 ou plus récent).
2. Ouvre le fichier `Respire.apk` téléchargé.
3. Android te demande d'autoriser l'installation d'applications depuis ton
   navigateur : accepte.
4. Si Google Play Protect propose d'analyser l'application, tu peux accepter.

**Tu as déjà Respire (1.5.2, ou la version du test Google Play) ?** Depuis la
1.5.3, Respire ne passe plus par Google : la nouvelle version ne s'installe pas
par-dessus l'ancienne. Une seule fois : dans l'ancienne Respire, Réglages →
Exporter mes données (garde le fichier en lieu sûr) ; désinstalle-la ; installe
la nouvelle ; au premier lancement, touche « J'ai déjà une sauvegarde de
Respire » et choisis le fichier. Les versions suivantes s'installeront de
nouveau par-dessus.

- Certificat de signature (SHA-256), le même pour toutes les versions à partir

## Important

**Respire n'est pas un dispositif médical.** L'application ne pose aucun
diagnostic et ne remplace ni médecin ni pharmacien. Le sevrage de l'alcool, en
particulier, peut être dangereux : ne t'arrête jamais brutalement seul si tu bois
beaucoup, parles-en à un professionnel de santé.
